
# Containerized Eaglercraft Relay

Utility repository that allows one-click deployment of the relay to many free hosting providers.

## Click one to deploy

Free:

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/CariLT01/eagrelay/tree/main)

Other options:

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template/new?template=https://github.com/CariLT01/eagrelay)

[![Deploy to Fly.io](https://img.shields.io/badge/Deploy%20to-Fly.io-24292e?style=for-the-badge&logo=flydotio)](https://fly.io/launch?repo=https://github.com/CariLT01/eagrelay)


If not listed here, in most providers, you can directly paste the repository URL.
